## 🧭 About Me

I'm a Software Engineer at **Capgemini**, Bengaluru — working on the **NBCUniversal / Comcast** engagement, shipping backend systems and CI/CD pipelines that run in production for **10M+ concurrent users**. My day-to-day stack is **.NET Core, C#, Angular, Azure, and REST APIs**.

Outside of the day job, I like breaking things on purpose and building infrastructure for fun:

- 🔐 Co-built **REdV01** — an autonomous AI pentesting agent (GRPO + LoRA fine-tuning, AWS Step Functions) that placed at the **AWS AI for Bharat Hackathon**
- ☁️ Designed and deployed a **private cloud on Proxmox VE** as a university project — co-authored a paper on the implementation
- 🎨 Also just as into **UI/UX** as I am into backend — portfolio's at [designsbypranav.site](https://designsbypranav.site)
- 📜 Microsoft Certified: **Azure Developer Associate** + **Generative AI Specialist**
